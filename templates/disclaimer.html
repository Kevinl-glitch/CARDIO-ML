Academic Purpose & Context

Darshan University — Computer Engineering Department

This application (CardioML) was built as part of the Machine Learning Course Project in accordance with the department Standard Operating Procedure (SOP). The primary educational objective is to master the end-to-end ML lifecycle:

  • Problem definition and exploratory data analysis (Week 1)
  • Data cleaning, outlier handling, and standardization (Week 2)
  • Model development including scratch algorithm implementation (Week 3)
  • Comprehensive model evaluation and validation (Week 4)
  • Cross-validation and hyperparameter optimization (Week 5)
  • Frontend UI engineering (Week 6)
  • Backend integration and cloud deployment (Week 7)

⚠️ Medical Notice

This tool is designed strictly for research, benchmarking, and instructional demonstration. The generated probability score is not a substitute for clinical diagnostics, laboratory blood panels, electrocardiograms (ECG), or professional medical consultation. If you or someone you know is experiencing symptoms of heart disease or acute discomfort, seek immediate medical attention.
